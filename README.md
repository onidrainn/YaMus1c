# YaMus1c 🎵

Клиент Яндекс.Музыки с минималистичным кастомным интерфейсом под классические версии iOS (включая iOS 6). Проект разработан на Objective-C с использованием UIKit и Theos.

## ✨ Возможности
- Тёмный минималистичный интерфейс и поддержка переключения тем (Тёмная, Светлая, Классическая iOS 6).
- Компактный плеер, оптимизированный под экраны 3.5" (iPhone 4/4S).
- Поддержка треков, плейлистов «Мне нравится», поиска и загрузок.

---

## ⚙️ Требования
- macOS / Linux
- [Theos](https://theos.dev/) с настроенным toolchain
- Установленный SDK для iOS (например, iPhoneOS 9.3 SDK)
- Джайлбрейк-устройство на iOS 5/6 для тестирования

## 🛠️ Build (Сборка)

Чтобы собрать проект и скомпилировать `.deb`-пакет с помощью Theos, выполните следующие команды в терминале:

```bash
# Перейдите в папку проекта
cd ~/YaMus1c

# Очистите старые артефакты сборки и скомпилируйте пакет
make clean && make package
```

После завершения сборки готовый пакет `.deb` появится в папке `./packages/`.

## 🚀 Launch Server (Установка и запуск на устройстве)

Для быстрого запуска python прослойки выполните:

```bash
pip3 install flask requests yandex_music
python3 main.py
```
